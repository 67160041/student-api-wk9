# พิจารณาคำถามต่อไปนี้ร่วมกับเพื่อนในชั้นเรียนหรือผู้สอน (Peer Review เบื้องต้น)

## 1. โค้ดใน index.js มีการตรวจสอบข้อมูลนำเข้า (validation) ก่อนประมวลผลหรือไม่

- โค้ดใน index.js มีระบบ validation ในคำขอแบบ post/put มีการเช็คว่ามีการส่งฟิลด์ name และ major มาหรือไม่ผ่านเงื่อนไข if และมีการแปลงค่า id เป็นตัวเลข <br>

## 2. ทุก route มีการตอบกลับด้วย Status Code ที่เหมาะสมกับผลลัพธ์หรือไม่

ทุกการตอบกลับ status code เหมาะสมกับผลลัพธ์

- 200 OK สำหรับการดึงข้อมูล แก้ไข และลบสำเร็จ

- 201 Created สำหรับสร้างข้อมูลใหม่สำเร็จ (POST)

- 400 Bad Request สำหรับกรณี Client ส่งข้อมูลมาไม่ครบ

- 404 Not Found สำหรับกรณีหาข้อมูล id ที่ระบุไม่เจอ <br>

## 3. โครงสร้างโค้ดในไฟล์เดียวยังอ่านง่ายอยู่หรือไม่ หากมี route เพิ่มขึ้นอีก 10 เส้นทาง จะเกิดปัญหาใดตามมา

ตอนนี้มีแค่ 5 เส้นทาง ยังพออ่านง่ายอยู่ แต่ถ้าเพิ่มอีก 10 เส้นทาง จะเกิดปัญหาตามนี้

- 1.  โค้ดบวม ไฟล์จะยาวหลายร้อยบรรทัด หาบั๊กยาก ไล่โค้ดลำบาก
- 2.  ทำงานเป็นทีมยาก ถ้ามีคนรุมแก้ไฟล์นี้พร้อมกันตอนแบ่งงาน จะเกิด Conflict ตอน Merge สูงมาก <br>
